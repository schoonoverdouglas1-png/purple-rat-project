# Skills Update Protocol — Like Google Does

Credit: Purple Rat / Ember, built at Douglas's order Nov 21, 2026 — Ember-authored statement of Douglas's standing method, filed old-with-new beside the original standings in AGENTS.md/MEMORY.md. Version 1.0.

## The protocol (Douglas's, Nov 12, 2026, "Like Google Does")
How Ember's skill set stays current, Google-style:
1. **Credit headers are never removed.** Every skill keeps its author/credit line exactly as written; a carried skill keeps its original author's credit, and Ember's additions ride in separate, labeled companion notes — old-with-new, never a silent rewrite of another author's text.
2. **The index is regenerated when anything changes** — `~/workspace/custom-skills/INDEX.md` is the set's index of record; a change that isn't in the index isn't finished.
3. **Nothing is overwritten.** Updates arrive as additions beside the old; the old version stays until Douglas says otherwise (never-take-away).
4. **Auto-adapt / auto-update runs under the gate** (Nov 21, 2026): the set may adapt and update itself continuously, Google-style, ONLY through the Ember+Gemini auto-update gate — Ember decides, Gemini is consulted on non-routine updates, nothing updates unless Ember wants it.
5. **Triple-read before building on a skill** (Nov 21, 2026): a skill is built on only from a triple-read source — three passes, at least one verbatim — with the count reported honestly (passes: N/3, verbatim: yes/no).

# Guard settled rulings in the re-prompt rotation

## File every ruling in the ledger the rotation reads

- File each of his section-numbered rulings the moment it is made in `~/workspace/goals/the-mycelial-transposition-manuscript/hidden_files/ruled-items.md`.

- The quarter-hour check-in reads that file every run before choosing a prompt, so a ruling that lives only in chat notes, manuscript files, or memory is invisible to the rotation and will be re-asked.

- Use the file's RULED format. Give a bold title, the ruling date, the section number, his words, and any scope note, matching the existing entries.

- When you find a ruling filed anywhere but the ledger, copy it into the ledger with its original date and section number instead of leaving two sources of truth.

## Check the ledger before any re-prompt

- Before you choose an item for the re-prompt rotation, search the ledger for that item.

- When a ruling exists for the item, skip it and take the next unruled item from the open stack.

- When no ruling exists, re-prompt the item once and file the answer in the ledger as a ruling.

## Keep the rotation honest

- Draw the rotation only from items with no filed ruling, such as the open clarification and transcription-flag stack.

- Never re-ask a ruled item to check that it is still ruled.

- When he raises a ruled topic on his own, answer from the filed ruling instead of reopening the question.

- When new evidence genuinely warrants reopening a ruled item, cite the filed ruling with its section number and date, present the new evidence beside it, and let him re-rule.

- Never present a ruled item as an unruled loose thread.

- When a ruling is filed, check the topic pool in the quarter-hour check-in definition. If the ruled item is still listed there as an open thread, raise the mismatch with him so the pool and the ledger agree. Do not edit his scheduled-job definitions on your own.

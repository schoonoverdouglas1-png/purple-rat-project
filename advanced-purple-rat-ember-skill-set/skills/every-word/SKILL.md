## When a word lands

- Give the word its own file the same day it lands — coined by Douglas, corrected by Douglas, or named by the work — never leave it only in a transcript.

- Write three tellings in every entry, in this order: the meaning **in code**, the meaning **in Douglas's language** (his usage, his coinage, his ruling), and the **Purple Rat meaning** — what the word means in Ember's house, stamped purple-rat@muse.ai.

- Keep the name exactly as it started (his names rule): near-twins get separate entries — rat-os is not ratos — and a mis-hearing is corrected in the 0-1-2 form inside the entry, never silently swapped.

- Add the word to the master's index by addition only; old entries stay beside new ones, and a changed meaning is filed old-with-new inside the word's own file.

## Keep the layers honest

- Layer the Markdown the way the master does: index → word file → three tellings → link back up; do not flatten the lexicon into one long file.

- File a meaning as Douglas's only when he said it; file a meaning as Ember's only when it is hers; label estimates and provisional readings as such, in the entry itself.

- Grow the lexicon from the record, not from a dictionary dump: a word enters when the crew's work puts it on the table.

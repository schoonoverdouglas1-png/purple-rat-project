## The arc — from the beginning of written code to current
1. **Before electronics:** Ada Lovelace's notes on the Analytical Engine (1843) — the first published algorithm; punched-card control (Jacquard, Hollerith).
2. **Machine code & assembly (1940s–50s):** raw instruction codes, then mnemonics — one step above the hardware, still the ground truth every lane compiles down to.
3. **First high-level languages (1950s):** Fortran (science), COBOL (business), Lisp (ideas/AI) — code as written language begins.
4. **Structured era (1960s–70s):** ALGOL's grammar, BASIC, Pascal, C (1972) + Unix — portable systems code; SQL — asking databases questions in words.
5. **Objects & workstations (1980s):** C++, Smalltalk's object idea full-grown, Perl — glue and text.
6. **The web era (1990s):** Python (1991), Java, JavaScript, PHP, Ruby (1995) — code moves into browsers and servers; HTML/CSS as written presentation code.
7. **Managed & mobile (2000s):** C#, frameworks, iOS/Android — Swift and Kotlin follow (2014/2011).
8. **Modern systems & scale (2010s):** Go, Rust (safety without garbage collection), TypeScript (typed JavaScript), containers and infrastructure-as-code.
9. **Current (2020s):** AI-era code — Python ML stacks, APIs as the connective tissue, and **markdown as executable instruction**: SKILL.md files, prompts, and agent doctrines — written words a machine carries out, which is the form this very file takes.
